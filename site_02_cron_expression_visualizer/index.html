Q: What is the 5-field Cron format?

The 5 fields represent: Minute (0-59), Hour (0-23), Day of Month (1-31), Month (1-12), and Day of Week (0-6, Sunday to Saturday).

Q: Does this work with Cloudflare Workers & GitHub Actions?

Yes! Both Cloudflare Cron Triggers and GitHub Actions workflow schedules use standard 5-field POSIX cron syntax.
